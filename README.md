# ADB Wi-Fi Connector

Утилита командной строки на Python 3 для быстрого автоматического обнаружения и подключения к Android-устройствам по беспроводной сети (Wi-Fi Debugging / mDNS) с поддержкой USB-fallback и интерактивного управления.

## Возможности

- **Автоматическое подключение:**
  - Поиск сервисов отладки Android через mDNS (`adb mdns services`).
  - Подключение по Wi-Fi (`adb connect <ip>:<port>`).
  - Fallback на USB при отсутствии беспроводного подключения с переводом в режим TCP/IP (`adb tcpip 5555`).
- **Интерактивная консоль управления:**
  - Установка APK файлов (с поддержкой выбора файла через диалог или ручной ввод).
  - Быстрый просмотр логов (`logcat`).
  - Перезагрузка устройства в различные режимы (`reboot`, `recovery`, `bootloader`).
  - Выполнение произвольных команд оболочки Android (`shell ...`).
- **Нулевые зависимости:** работает на чистой стандартной библиотеке Python 3 (Tkinter подключается лениво только при открытии GUI диалога выбора файла).

## Использование

```bash
python ADB_WIFI_CONNECTOR.PY
```

### Параметры запуска:

- `--ip <ip>` — задать предпочтительный IP-адрес устройства (или переменная окружения `ADB_WIFI_IP`).
- `--port <port>` — задать порт подключения (или переменная окружения `ADB_WIFI_PORT`).
- `--adb <path>` — путь к исполняемому файлу `adb.exe` (или переменная окружения `ADB_PATH`).

## Требования

- Python 3.8+
- Android SDK Platform-Tools (`adb`) в `PATH` или указанный через флаг `--adb`.
